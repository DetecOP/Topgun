## 4. สคริปต์อธิบาย (คนอธิบายอ่านคืนนี้ 2 รอบ)
### แบบ 1 นาที
> agent ของเราใช้กฎ Python ล้วนในการตั้งราคา ไม่ให้ LLM ตัดสินราคา หลักคิดคือผู้ซื้อเรียงซองจากราคาต่อคุณภาพ (ราคา ÷ TV) ต่ำไปสูง แล้วรับจนครบที่ต้องการ เราจึงต้อง (1) ให้กระสอบของเราเข้ากลุ่มผู้ซื้อที่จ่ายดีที่สุดที่สเปกรับได้ และ (2) ตั้งราคาให้อยู่ด้านสูงสุดของส่วนที่ยังได้รับ
> ทำ 3 อย่าง: **ตรวจสเปก** ล็อตที่ค่าตัวอย่างชิดขอบ ด้วยซอง 1 กระสอบในรอบซ้อมที่ไม่เสียของ · **ตั้งราคาจากราคาตัดจริง** ของตลาดแข่งรอบก่อน ลบด้วย 1.5 เท่าของความผันผวน · **ขายเต็ม capacity ทุกรอบ** ไม่กั๊กของ เพราะของเหลือคิดแค่ 80%

### แบบ 3 นาที (เพิ่มจากแบบ 1)
1. **ปัญหาจากด่าน 2:** ล็อต 3 (37% ของมูลค่า) ค่าชื้นตัวอย่าง 12.6 เกินขอบ Commercial 0.1 → ขายได้แค่ Instant ราคาต่ำ · ตัวอย่างมี noise ของจริงอาจผ่าน → จึงต้องตรวจด้วยซองจริง (`SPEC_PROBE`) ผลตอบ SPEC_MISMATCH = ไม่ผ่านแน่ · ACCEPTED/OUTBID = ผ่าน
2. **ราคา:** ราคาตัด = ราคาสูงสุดที่ผู้ซื้อรับ ÷ TV สูงสุดของล็อตที่ผ่านสเปก (ทุกทีมได้ล็อตชุดเดียวกัน) · ใช้ค่ากลาง = min(ล่าสุด, เฉลี่ย 3 รอบ) − 1.5 × ความผันผวน · ผู้ซื้อราคานิ่งเว้นน้อย ขาลงเว้นมาก
3. **ช่วงต้น R1–R2:** ตั้งไม่เกินราคาตัดต่ำสุดที่เคยเห็น เพื่อขายออกแน่ · **กระจายผู้ซื้อ** ไม่เกิน 60% ต่อราย
4. **เทศกาล R6–8:** มีสวิตช์ `FESTIVAL_HOLD` ให้คนตัดสินจากขนาดใบ Specialty ที่เห็นใน R3–R5
5. **LLM ผู้จัด:** ใช้โหมดเงา อ่านสถานการณ์ตลาดเป็นป้าย (ปกติ / ถูกตัดราคา / ของล้น / ขาดตลาด / เทศกาล) บันทึกใน log แต่ไม่เปลี่ยนซอง · เหตุผล: ทดสอบแล้ว LLM ตีความตัวเลขดิบผิดทิศ (แพ้ราคาแล้วขึ้นราคา 10/10) และทายทิศราคาแพ้กฎง่ายๆ → ให้ Python ตีความตัวเลขเป็นใช่/ไม่ใช่ก่อน แล้ว LLM ตอบเฉพาะผลตรวจ
6. **ระหว่างแข่ง:** คนใช้ AI (Claude) อ่าน log สรุปผลรอบ แล้วเลือกค่าตั้งจากตารางที่ทดสอบไว้ เช่น ของล้น / ขาดตลาด / เทศกาล แล้วรีสตาร์ท · ไม่ส่งหรือแก้ซองด้วยมือ · ทุกซองอยู่ใน log พร้อมเวลา
7. **วิธีทดสอบ:** replay กับข้อมูลตลาดแข่งด่าน 2 จริง (PR 0.9656) + ตลาดจำลองแบบจับคู่ seed · ไอเดียที่ไม่ผ่านตัดทิ้ง (ตามแนวโน้ม, ค่าเฉลี่ยแทน min, LLM ทายราคา)

8. **ด่าน 3 (≥ 5 ล็อต 45 กระสอบ · ซ้อม 2 + จริง 15):** โค้ดอ่านจำนวนล็อต/รอบจากตลาด ไม่ล็อกตัวเลข · ซ้อม 2 รอบใช้ตรวจสเปกได้มากขึ้น · ซ้อมเหลือ 1 รอบ → ตรวจต่อใน R1–R2
9. **ระยะเผื่อ (กันตัวเลขคลาดและถูกตัดราคา):** ไม่ตั้งชิดราคาตัด · ค่ากลางเลือกตัวต่ำ (min) · ลบ 1.5 × ความผันผวน · ลบอีก 0.005 · กระจายผู้ซื้อ ≤ 60% · ถูกตัดราคาซ้ำ 2 รอบ → คนปรับค่าตั้ง
