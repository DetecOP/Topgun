## 1. งานของ LLM (ตอบคำถาม 1)
**ทำนาย ไม่ตัดสิน**: ต่อผู้ซื้อแต่ละราย ให้ LLM ตอบ 2 อย่างจากรายการปิด
- `direction` รอบหน้า: `down` / `flat` / `up` (เทียบมัธยฐานราคาตัดรอบล่าสุด · ±0.01)
- `risk`: `stable` / `volatile` / `break` (break = มีโอกาสร่วงกะทันหัน แบบชุมพร R2 1.045 → 1.003)
- พร้อมผลตรวจ true/false ก่อนตอบ (แบบ v3 ที่ผ่านแล้ว) เช่น `median_fell_2_rounds`, `offers_per_bag_rising`, `next_round_is_festival`, `next_round_is_closing`

**Python แปลงเป็น k (ตายตัว ไม่ให้ LLM เลือกตัวเลข)**

| direction / risk | k (ตัวคูณความผันผวนใน `market_info`) |
|---|---|
| `down` หรือ `break` | 2.0 (เว้นมากขึ้น) |
| `flat` + `stable` | 1.0 (ใกล้ขอบบนขึ้น) |
| อื่นๆ | 1.5 (ค่าเริ่มเดิม) |

ทำไมเลือกงานนี้: ตัวแปรที่มีผลกับ PR คือ "ระยะเว้นต่ำกว่าจุดตัด" · ค่า k ทั้ง 3 ทดสอบในโค้ดแล้ว · LLM ผิด = แค่ใช้ k อื่นในชุดที่ปลอดภัย

**ข้อมูลที่ให้ LLM เห็นเพิ่ม (กฎปัจจุบันไม่ใช้)**
- ประวัติต่อผู้ซื้อ ≤ 6 รอบล่าสุด (รวม P1–P2): มัธยฐาน/ต่ำสุด/สูงสุดราคาตัด · fill · ซองต่อกระสอบ · ขนาดใบ · ผลซองเรา (ขายได้/แพ้/เกินเพดาน)
- ปฏิทินรอบหน้าและอีก 2 รอบ (ปกติ/เทศกาล/ใกล้ปิด · demand_weight)
- ราคาตัดของ**ประเภทอื่น**รอบเดียวกัน (เช่น Instant ลด ขณะ Commercial นิ่ง)
- ตัวเลขดิบใช้ได้ในงานนี้ เพราะเป็นการ "ทำนาย" ไม่ใช่ "ตัดสินทิศราคาของเรา" (ความผิดพลาด 18 พ.ย. คือแปลผลแพ้แล้วขึ้นราคา → ตัวกันข้อ 3 ปิดทางนั้น) · ปัดทศนิยม 3 ตำแหน่ง · ~800–1,200 token

## 2. เฉลยและเกณฑ์ผ่าน (ตอบคำถาม 2)

### K0 · ประตูแรก: ขอบบนของผลได้ (ไม่ใช้ LLM)
- replay ด่าน 2 (กฎชนะเดิม · ซองตรวจ = ตก) โดยเลือก k ต่อ (ผู้ซื้อ, รอบ) แบบ "รู้คำตอบ" (oracle) = k ใน {1.0, 1.5, 2.0} ที่ได้เงินมากสุดรอบนั้นโดยไม่แพ้
- oracle − ฐาน (k = 1.5) **< 0.003 → หยุดทั้งโครงการ** (เลือก k ถูกทุกครั้งยังได้ไม่คุ้ม) · ≥ 0.003 → ทำต่อ

### เฉลยรายจุด
- จุด = (ผู้ซื้อ, รอบ t) ที่รอบ t และ t+1 มีราคาตัด · ~35 จุด
- `direction` เฉลย = มัธยฐานราคาตัดรอบ t+1 − รอบ t (> +0.01 up · < −0.01 down · อื่น flat)
- `k` เฉลย = k ของ oracle ใน K0

### คู่เทียบ (baseline) ที่ LLM ต้องชนะ
| ชื่อ | วิธี |
|---|---|
| B0 | k = 1.5 ทุกครั้ง (โค้ดปัจจุบัน) · direction = flat |
| B1 | กฎ Python ข้อมูลเดียวกัน: ความชัน 3 รอบ (< −0.01 = down) · sd > 0.02 = volatile · ร่วง > 0.03 ในรอบเดียวที่เคยเห็น = break → ตาราง k เดียวกัน |
| B2 | ตามแนวโน้มล้วน: direction = ทิศของรอบล่าสุด |

### เกณฑ์ผ่าน (ครบทุกข้อ)
1. ออฟไลน์ ~35 จุด: ความแม่น `direction` ของ LLM ≥ max(B1, B2) + 10 จุด% · และจำนวน "ทำนาย up/flat แต่จริง down" (พลาดที่ทำให้แพ้) ≤ ของ B1
2. replay ด่าน 2 วงปิด (ข้อ 4): LLM ≥ B1 + 0.002 และ ≥ B0 · ของค้างไม่เพิ่ม
3. ความนิ่ง: ถามซ้ำ 3 ครั้ง ตอบเหมือนกัน ≥ 90% · สลับลำดับผู้ซื้อ ป้ายเปลี่ยน ≤ 10%
4. ตลาดจำลองด่าน 3: LLM − B1 ไม่แย่เกิน 2 SE (เป็นแค่ตัวกันความปลอดภัย เพราะตลาดจำลองสร้างจากเส้นราคาจริงเดียวกัน = วนกลับ)
- **ถ้า B1 ผ่านข้อ 2 แต่ LLM ไม่ชนะ B1** → ใช้ B1 (Python ล้วน) เป็นตัวเลือก ไม่ใช้ LLM · ทดสอบ B1 ตามเกณฑ์ปกติก่อนเปิด
- ข้อ 1 กับ 35 จุดแยกได้แค่ผลใหญ่ (10 จุด% ≈ 3–4 จุด) → ห้ามแก้ prompt เกิน 3 รอบ และ**ห้ามใช้จุดจริงเป็นตัวอย่างใน prompt** (ข้อ 5)

## 3. ต่อเข้า agent + ตัวกัน (ตอบคำถาม 3)
```
# ถามตอนได้ round_results ของรอบ t (ช่วงจับคู่ ~1 นาที) · ไม่แก้ซองที่ส่งไปแล้ว
facts = trend_facts(model, calendar)          # ข้อ 1
ans   = llm.ask(facts, TREND_SCHEMA, timeout=20)
k_map = {buyer: K_TABLE[ans.direction, ans.risk]} ถ้าผ่าน validate ไม่งั้น {}
k_map = trend_guard(k_map, model, round)
ctx.k_override = k_map                         # ใช้ตอนเปิดรอบ t+1 ใน market_model.target(k=...)
log("llm_trend", raw=ans, used=k_map, rule=B1_k_map, base=1.5)
```
`trend_guard` (Python · ทิ้งค่าที่ผิดเงื่อนไข → k = 1.5):
- รอบที่เราแพ้ (OUTBID/ABOVE_LIMIT) ผู้ซื้อรายนั้น → k ต้อง ≥ 1.5 (ห้ามเว้นน้อยลงหลังแพ้)
- k = 1.0 ได้เฉพาะเมื่อ 2 รอบล่าสุดเราขายครบทุกซองให้ผู้ซื้อรายนั้น
- ไม่ใช้ในรอบซ้อม · R1–R2 (EARLY_SURE คุมอยู่) · รอบสุดท้าย
- เปลี่ยนจากรอบก่อนได้ทีละขั้น (1.0 ↔ 1.5 ↔ 2.0)
- ราคาสุดท้ายยังผ่านตัวกันเดิมทั้งหมด (ต่ำกว่าราคาที่เพิ่งแพ้ · พื้น · เพดาน)
- LLM ไม่ตอบทันเปิดรอบ → k = 1.5
ค่าตั้ง: `LLM_TREND=off|shadow|on` (ค่าเริ่ม off) · ใช้คำขอเดียวกับ shadow เดิมได้ (รวม schema) เพื่อไม่เพิ่มจำนวนคำขอ หรือแยก 1 คำขอ/รอบ (รวม ≤ 2/รอบ · ไม่ติด 20/นาที)

## 4. วัดวงปิดเมื่อข้อมูลจริงมีเส้นเดียว (ตอบคำถาม 4)
1. **replay ด่าน 2 ทีละรอบ (หลัก)**: ที่เปิดแต่ละรอบ ให้ LLM เห็นเฉพาะข้อมูลถึงรอบก่อน (ห้ามรั่วรอบอนาคต) → k → replay รอบนั้นด้วยกฎชนะเดิม → เดินต่อ · ได้ PR 1 ตัวเลขต่อวิธี (LLM / B0 / B1 / oracle) · LLM ถาม 3 ครั้ง (temperature 0 แต่ดูความนิ่ง) รายงานทั้ง 3
2. **ทดสอบเลื่อนเวลา (แทน SE)**: เริ่ม replay จาก R2, R3, R4 (ตัดรอบต้น) → 3 เส้นย่อย · ต้องชนะ B1 อย่างน้อย 2/3
3. **ตลาดจำลองด่าน 3** ~30 เกม (1–2 คำขอ/รอบ · 15 รอบ ≈ 1.5 นาที/เกม) เป็นตัวกันความปลอดภัยเท่านั้น
4. **วันแข่ง = ข้อมูลจริงชุดที่ 2**: เปิด `LLM_TREND=shadow` (ถ้าผ่าน G1 เดิม) → หลังแข่งวัดข้อ 1 ซ้ำด้วย log ด่าน 3 (~15 รอบ × 5 ผู้ซื้อ ≈ 70 จุด) → ใช้ตัดสินรอบหน้า

## 8. รอบ 2 · คำตัดสินจากผลเบื้องต้นของ A (34 จุด)

ผล A: เฉลยทิศ up 12 · flat 3 · down 19 · กลับทิศรอบล่าสุด 22/34 · down เสมอ 19/34 · ตามทิศล่าสุด 5/34 · LLM 8/34 (ดิบ) และ 11/34 (มีตัวแปรช่วย) · LLM ไม่เคยทาย up

**LLM อ่านแนวโน้ม: หยุด** (ไม่ทำ K1–K4 ไม่ทำแบบ "LLM เลือกระหว่าง 2 ทางของ Python")
- แพ้แม้แต่ "down เสมอ" (19/34) · ไม่เคยทาย up ทั้งที่ up มี 12 จุด = เอนเอียง ไม่ใช่อ่านข้อมูล
- ทางเลือก 2 ทางก็ต้องให้ LLM ตัดสินจากสัญญาณเดียวกันที่มันจับไม่ได้ → ไม่มีเหตุให้คาดว่าดีขึ้น
- LLM วันแข่งคงเดิม: `LLM_LABEL=shadow` · `LLM_TREND` ไม่ต้องเขียน

**"แกว่งกลับ" ตีความอย่างระวัง**
- กลับทิศ 22/34 ชนะ "down เสมอ" แค่ 3 จุด (เกมเดียว) → ยังแยกจากโชคไม่ได้
- คำอธิบายที่ง่ายกว่า: มัธยฐานต่อรอบมี noise (คนละใบ คนละล็อตที่ขายราคาสูงสุด) รอบบนระดับที่ไหลลงช้าๆ → ผลต่างรอบต่อรอบกลับทิศเองโดยธรรมชาติ · แปลว่าตัวทำนายที่ดีคือ **ค่าเฉลี่ยหลายรอบ (เกลี่ย)** ไม่ใช่ "หลังลดแรงให้ตั้งสูงขึ้น"
- โค้ดตอนนี้ใช้ `min(มัธยฐานล่าสุด, ค่าเฉลี่ย 3 รอบ)` เป็นศูนย์กลาง = เกลี่ยเฉพาะขาขึ้น · ขาลงตามค่าล่าสุดเต็มๆ

**ทดสอบ Python 1 ตัว (ไม่จูน): `MKT_CENTER=mean`**
```
# market_model.market_info
center = mean(meds) ถ้า MKT_CENTER == "mean" ไม่งั้น min(meds[0], mean)    # meds = มัธยฐาน ≤ 3 รอบล่าสุด
ตัวกัน: รอบล่าสุดเราแพ้ (OUTBID) ผู้ซื้อรายนี้ → ใช้ min(...) แบบเดิม
        ร่วงรอบเดียว > 0.03 (แบบชุมพร R2) → ใช้ min(...) แบบเดิม
vol = center − k × max(sd, within/2) − MKT_VOL_MARGIN    # ส่วนอื่นเหมือนเดิม
```
วัด: test (ตัวกัน 2 ข้อ + ค่าเริ่มไม่เปลี่ยน) · replay ด่าน 2 (ซองตรวจ = ตก) · ราคานี้ชนะทุกใบรอบหน้ากี่จุดจาก 34 (เทียบ vol เดิม 15/34) · จำลองด่าน 3 จับคู่ 300 เกม noise 0.3/0.48
เกณฑ์: replay ≥ 0.9656 + 0.002 · จำลอง Δ > 0 ที่ z ≥ 3 · จุดที่ชนะทุกใบไม่ลดเกิน 2 จาก 15 → ผ่านทั้งหมดจึงเปิดค่าเริ่ม · ไม่ผ่าน = ทิ้ง ห้ามลองค่ากลางแบบอื่น (EWMA, น้ำหนัก ฯลฯ) เพื่อหาตัวที่ผ่าน
หมายเหตุ: ตลาดจำลองสร้างจากเส้นราคาด่าน 2 + noise แบบสุ่มอิสระ → การเกลี่ยจะดูดีในตลาดจำลองโดยโครงสร้าง · ให้น้ำหนัก replay มากกว่า

### 8.1 ผล K0 (มาหลังคำตัดสินหัวข้อ 8): **ยืนยันหยุด LLM แนวโน้ม**
