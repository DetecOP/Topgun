### ข้อ 1 · ตัวแปร + if
กำหนด `moisture = 13.2` ให้พิมพ์:
- `"ชื้นเกิน"` ถ้ามากกว่า 12.5
- `"แห้งเกิน"` ถ้าน้อยกว่า 10
- `"พอดี"` ถ้าไม่เข้าเงื่อนไขข้างบน

**ผลที่ควรได้:** `ชื้นเกิน`

---

### ข้อ 2 · list + for
กำหนด `prices = [98, 105, 110, 92, 101]` ให้หา**ค่าเฉลี่ย**และ**ราคาสูงสุด** โดยใช้ `for` (ห้ามใช้ `sum()` หรือ `max()`)

**ผลที่ควรได้:** `เฉลี่ย 101.2 สูงสุด 110`

---

### ข้อ 3 · dict + def
เขียนฟังก์ชัน `lot_value(lot, base_price)` รับ dict หน้าตาแบบนี้
```python
lot = {"id": "A", "weight": 120, "defect_pct": 6}
```
แล้วคืนมูลค่ารวม = `weight × base_price × (1 − defect_pct × 0.015)`

ทดสอบด้วย `base_price = 100`
**ผลที่ควรได้:** `10920.0`

---

### ข้อ 4 · แปลง JSON (จำลองคำตอบจาก API)
ข้อความด้านล่างจำลองคำตอบจาก API **รูปแบบนี้แต่งขึ้นเอง ของจริงยังไม่ทราบ**
```python
text = '{"round": 3, "results": [{"lot": "A", "sold": true, "price": 105}, {"lot": "B", "sold": false, "price": 90}, {"lot": "C", "sold": true, "price": 112}]}'
```
ใช้ `json.loads()` แปลงเป็น dict แล้วพิมพ์ชื่อล็อตที่ขายได้ และยอดรวมราคาของล็อตที่ขายได้

**ผลที่ควรได้:**
```
รอบ 3 ขายได้: ['A', 'C'] รวม 217
```

### ข้อ 5 · เขียน/อ่านไฟล์ + try/except
1. เขียนฟังก์ชัน `save_log(path, round_no, lot, price, result)` ที่**เขียนต่อท้าย**ไฟล์ CSV ทีละบรรทัด เช่น `1,A,105,ขายได้`
2. เรียกใช้ 3 ครั้งด้วยข้อมูลอะไรก็ได้
3. เขียนฟังก์ชัน `count_sold(path)` ที่อ่านไฟล์แล้วนับว่า "ขายได้" กี่ครั้ง
   - ถ้าไฟล์ไม่มีอยู่ ให้จับ `FileNotFoundError` แล้วคืนค่า 0 แทนการพัง
4. ทดสอบ `count_sold("ไม่มีไฟล์นี้.csv")` ต้องได้ `0`

**ผลที่ควรได้ (ตัวอย่าง):** `ขายได้ 2 ครั้ง` และ `ไฟล์ไม่มี: 0`
