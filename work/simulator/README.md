# โมเดลขายล่วงหน้า + ตลาดจำลอง

> คอนเซ็ปต์ทีม: **ขายอัตโนมัติ ขายเร็ว ขายล่วงหน้าได้ก่อนข้อมูลเซ็นเซอร์มาถึง**
> ⚠️ ค่าทุกตัวยังเป็นค่าสมมติ ตลาดจำลองแต่งขึ้นเอง และ DRY_RUN เปิดอยู่ ไม่มีการส่งอะไรออกไปจริง

## ไฟล์ (ถอดเปลี่ยนได้ทีละชิ้น)
| ไฟล์ | หน้าที่ | ต้องแก้เมื่อได้กติกาจริง? |
|---|---|---|
| `config.py` | ค่าตั้งต้นทั้งหมด: DRY_RUN, เพดาน, โหมดคะแนน, ค่าประเมินเริ่มต้น | ✅ แก้ค่า |
| `valuation.py` | **รู้ค่าของ**: ประเมินมูลค่า/กก. ถ้ายังไม่มีผลวัดก็เติมค่าที่คาดไว้ (ขายล่วงหน้า) อ่านค่าสูตรจากชีท "ตั้งค่า" | ✅ เปลี่ยนสูตรเป็นของจริง |
| `scoring.py` | สูตรคะแนน 3 แบบ: `diff` / `ratio` / `penalty` | ✅ เลือกหรือเพิ่มสูตรจริง |
| `pricer.py` | **ตั้งราคาให้พอดี**: เรียนจากผลขายว่าผู้ซื้อแต่ละคนรับราคาได้แค่ไหน | ❌ ใช้ได้เลย |
| `agent_core.py` | สมองของ agent: เลือกล็อต ผู้ซื้อ และราคาของแต่ละรอบ + `submit()` (ยังไม่เชื่อม API) | 🔶 เชื่อม `submit()` กับ API จริง |
| `market_sim.py` | ตลาดจำลองที่มีคู่แข่งและผู้ซื้อที่มีราคาลับ | 🔶 ปรับให้เหมือนตลาดจริง |
| `run_sim.py` | เปรียบเทียบกลยุทธ์ / ดูทีละรอบ | — |
| `competitors.py` | คู่แข่งจำลอง 81 กลยุทธ์แบบใช้กฎ (คาดจาก clue ในไฟล์ TGR) | 🔶 ปรับเมื่อเห็นพฤติกรรมทีมจริง |
| `arena.py` | สนาม 16 ทีม: เราแข่งกับคู่แข่ง 86 แบบ (รวมทีมเก่ง 5 แบบ) วัดอันดับ | 🔶 ปรับขนาดตลาดตามจริง |
| `arena_tune.py` | ลองปรับค่าโมเดลเราในสนามหลายทีม | — |
| `ablation.py` | ทดสอบทีละส่วนในตลาดเดี่ยว | — |

> ผลสนามหลายทีมและข้อค้นพบเรื่อง "รอผลวัดชนะขายล่วงหน้าเมื่อของล้นตลาด" อยู่ใน [../RESEARCH.md](../RESEARCH.md) ข้อ 7

## วิธีรัน (จากโฟลเดอร์ work)
```powershell
.venv\Scripts\python.exe simulator\run_sim.py          # เปรียบเทียบ 3 กลยุทธ์ × 3 สูตรคะแนน (300 เกม, ~2 วินาที)
.venv\Scripts\python.exe simulator\run_sim.py --demo   # ดู agent ตัดสินใจทีละรอบ 1 เกม
```

## ผลทดลองล่าสุด (v2 ปรับตามงานวิจัย, ตลาดสมมติ, 300 เกม)
| กลยุทธ์ | diff | ratio | penalty |
|---|---|---|---|
| **ขายล่วงหน้า+เรียนรู้ v2 (ทีม)** | **3039** | 0.82 | **865** |
| ขายล่วงหน้า+เรียนรู้ v1 | 2940 | **0.84** | 154 |
| รอผลวัดก่อน+เรียนรู้ v2 | 2849 | **0.84** | 128 |
| ขายล่วงหน้า บวก 8% คงที่ | 801 | 0.58 | −1586 |

v2 เพิ่มจาก v1: ยืมข้อมูลผู้ซื้อคนอื่น (pool) และบวกระยะเผื่อตอนขายล่วงหน้า เพื่อกัน winner's curse
เหตุผลและผลทดสอบละเอียด (1000 เกมแบบจับคู่) อยู่ใน [../RESEARCH.md](../RESEARCH.md)
ทดสอบแยกทีละส่วนใหม่ได้ด้วย `.venv\Scripts\python.exe simulator\ablation.py`

## เมื่อได้กติกาจริง (17 พ.ย.)
1. แก้ชีท "ตั้งค่า" ใน Excel หรือเขียนสูตรจริงใน `valuation.py`
2. ตั้ง `SCORE_MODE` ใน `config.py` (หรือเพิ่มสูตรใหม่ใน `scoring.py`)
3. แก้ `market_sim.py` ให้เหมือนตลาดจริง (จำนวนรอบ ผู้ซื้อ วิธีเปิดซอง) แล้วรัน `run_sim.py` ใหม่
4. เชื่อม `agent_core.plan_offers()` เข้ากับ starter agent **โดยเปิด DRY_RUN ไว้ก่อนเสมอ**
