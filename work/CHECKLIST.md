## 4. ⚠️ ข้อขัดกันเรื่อง LLM / SLM 1.5B

| ด้าน | ข้อความ | แหล่ง |
|---|---|---|
| A | "ใช้ LLM ที่ผู้จัดเตรียมให้เท่านั้น" | T3 หน้า 4 (ท้ายสไลด์) |
| A | "ไม่ต้องมี GPU และไม่ต้องติดตั้ง LLM เอง" | T3 หน้า 7 (ท้ายสไลด์) |
| B | "เครื่องต้องรัน SLM ประมาณ 1.5B" | **ไม่พบในไฟล์ใดเลย** (ค้นแล้วใน T1, T2, T3, APP, EQ, PREP) |
| B (ใกล้เคียง) | Pi 5 8GB "รัน Local SLM + CV สำหรับ bean grading" ไม่ระบุขนาดโมเดล | EQ แถว 3 (ไฟล์ของทีมเอง ไม่ใช่กติกา) |
| B (ใกล้เคียง) | "ใช้ LLM ของผู้จัดเท่านั้น ขัดกับกติกา SLM 1.5B ในเครื่อง" | PREP ชีท รูปแบบโจทย์ ข้อ 33 (บันทึกของทีมเอง) |

**ขัดกันตรงไหน:**
1. **ใครเป็นคนจัดหาโมเดล:** A บอกว่าผู้จัดเตรียมให้ และห้ามใช้ตัวอื่น ส่วน B บอกว่าเครื่องเราต้องรันโมเดลเอง
2. **ต้องติดตั้งเองหรือไม่:** A บอกตรงๆ ว่าไม่ต้องติดตั้ง LLM เอง แต่ถ้าต้องรัน SLM ในเครื่อง ก็ต้องติดตั้งและดาวน์โหลดโมเดล
3. **ฮาร์ดแวร์:** A บอกว่าไม่ต้องมี GPU ส่วน SLM 1.5B ไม่ต้องใช้ GPU ก็รันได้ แต่ต้องมี RAM และพื้นที่ดิสก์เพิ่ม
4. **ที่มาของกติกา B ยังไม่ทราบ:** อาจเป็นกติกาของ Track 2 (ที่ใช้ Raspberry Pi) หรือกติกาภาพรวมฉบับอื่นที่ไม่มีอยู่ในเครื่อง

**ตอนนี้ในเครื่องมี** ollama พร้อม `qwen2.5:1.5b` (986 MB) อยู่แล้ว จึงเตรียมไว้ทั้งสองทาง แต่จะ**ไม่ใช้**ใน agent จนกว่าผู้จัดยืนยัน
