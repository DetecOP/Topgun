## 2. สิ่งที่ Track 3 ต้องทำ

**โจทย์:** "The Next-Gen Market" ตลาดกาแฟที่ให้ AI Agent เป็นคนขายแทน [น.1]

- เราเป็น **ผู้ขาย** เมล็ดกาแฟโรบัสตาดิบ ส่วนคนที่ขายจริงคือ AI Agent ที่เราเขียน [น.2]
- **มีของ:** เมล็ดกาแฟหลายล็อต แต่ละล็อตคุณภาพไม่เท่ากัน [น.2]
- **มีผู้ซื้อ:** โรงคั่วและโรงงานหลายแบบ แต่ละรายต้องการของไม่เหมือนกัน [น.2]
- **มีคู่แข่ง:** ทีมอื่นก็ขายให้ผู้ซื้อกลุ่มเดียวกัน [น.2]
- ข้อมูลกาแฟในตลาดเป็นข้อมูลจำลอง [น.2]

**วิธีเล่น** [น.3]
1. **รู้ค่าของ:** ประเมินว่าล็อตของตัวเองมีค่าเท่าไร จากผลวัดตัวอย่าง
2. **เสนอขายแบบปิดซอง:** ทุกรอบ เลือกว่าจะขายล็อตไหน ให้ใคร ในราคาเท่าไร
3. **ดูผลแล้วปรับ:** ผลว่าขายได้หรือไม่ได้ ใช้เป็นข้อมูลของรอบถัดไป

- **คะแนน** ดูจากว่าขายได้คุ้มแค่ไหนเมื่อเทียบกับมูลค่าจริงของของตัวเอง ได้ล็อตไม่ดีก็ยังชนะได้ [น.3]
- กติกาและสูตรทั้งหมดจะสอนในวันที่ 17 พ.ย. [น.3]

**Agent** คือโปรแกรมที่วนทำ 3 อย่าง [น.4]
1. **ดู:** ถามตลาดผ่าน API ว่าตอนนี้สถานการณ์เป็นอย่างไร
2. **คิด:** ตัดสินใจว่าจะเสนอขายอะไร ในราคาเท่าไร
3. **ทำ:** ส่งข้อเสนอขาย แล้ววนใหม่

- ทุกทีมได้ **starter agent** ที่เล่นจนจบเกมได้ตั้งแต่แรก งานของเราคือทำให้มันเก่งขึ้น [น.4]
- **ใช้ LLM ที่ผู้จัดเตรียมให้เท่านั้น** [น.4]

**ข้อบังคับ:** ในช่วง 2 และ 3 agent ต้องส่งคำสั่งเอง **ห้ามส่งด้วยมือ** แต่แก้โค้ด agent ระหว่างแข่งได้ [น.5]

> หมายเหตุ: ในคำสั่งเดิมคุณเรียก Track 3 ว่า "Agent-based Bidding" แต่ PDF บอกว่าเราเป็น **ฝ่ายขาย** ที่ยื่นข้อเสนอแบบปิดซอง ไม่ใช่ฝ่ายประมูลซื้อ
