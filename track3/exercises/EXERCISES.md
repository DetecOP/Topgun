# แบบฝึก 5 ข้อ (ไม่ต้องใช้อินเทอร์เน็ต)

ให้เขียนคำตอบแต่ละข้อเป็นไฟล์ `ex1.py` … `ex5.py` ไว้ในโฟลเดอร์ `exercises`
เฉลยอยู่ในโฟลเดอร์ `exercises/solutions/` **ลองทำเองก่อนค่อยเปิดดู**

วิธีรัน (เปิด Terminal ที่ `track3` ใน repo):
```powershell
.\.venv\Scripts\python.exe exercises\ex1.py
```

> ตัวเลขในแบบฝึกเป็นข้อมูลสมมติเพื่อฝึกเขียนโค้ด ไม่ใช่สูตรหรือกติกาของการแข่งขัน

---

## ข้อ 1: list และ dict
```python
lots = [
    {"id": "A1", "kg": 100, "moisture": 12.1},
    {"id": "A2", "kg": 80,  "moisture": 13.4},
    {"id": "B1", "kg": 120, "moisture": 11.8},
]
```
ให้ใช้ `for` พิมพ์ `id` และ `kg` ของทุกล็อต แล้วพิมพ์น้ำหนักรวมทั้งหมด
**ผลที่ควรได้:** บรรทัดสุดท้ายคือ `รวม 300 kg`

## ข้อ 2: def และ if
เขียนฟังก์ชัน `moisture_label(m)` ที่คืนค่า
- `"แห้ง"` ถ้า m < 12
- `"ปกติ"` ถ้า 12 ≤ m ≤ 13
- `"ชื้น"` ถ้า m > 13

แล้ววนพิมพ์ป้ายของทุกล็อตจากข้อ 1
**ผลที่ควรได้:** `A1 ปกติ` · `A2 ชื้น` · `B1 แห้ง`

## ข้อ 3: เขียนและอ่านไฟล์ JSON
1. บันทึก `lots` จากข้อ 1 ลงไฟล์ `lots.json` (ใช้ `ensure_ascii=False`, `indent=2`)
2. อ่านไฟล์กลับมา แล้วพิมพ์ว่าล็อตไหนหนักที่สุด

**ผลที่ควรได้:** `หนักที่สุด: B1 (120 kg)`

## ข้อ 4: try/except
มี list ของราคาที่ผู้ใช้พิมพ์เข้ามา บางตัวพิมพ์ผิด:
```python
raw = ["85", "90.5", "abc", "", "77"]
```
ให้แปลงเป็น float ทีละตัว ถ้าแปลงไม่ได้ให้พิมพ์เตือนแล้วข้ามไป จากนั้นพิมพ์ค่าเฉลี่ยของตัวที่แปลงได้
**ผลที่ควรได้:** เตือน 2 ครั้ง และ `เฉลี่ย 84.17` (ปัด 2 ตำแหน่งด้วย `round(x, 2)`)

## ข้อ 5: requests กับเซิร์ฟเวอร์ฝึก
ก่อนเริ่ม ให้เปิด Terminal อีกหน้าต่างแล้วรัน `.\.venv\Scripts\python.exe toolspractice_server.py` ค้างไว้
1. GET `http://127.0.0.1:8000/lots` แล้วพิมพ์จำนวนล็อต
2. GET `/me` **โดยไม่ใส่ token** แล้วพิมพ์ status code (ควรได้ 401)
3. GET `/me` โดยใส่ header `Authorization: Bearer practice-token` แล้วพิมพ์ชื่อทีม
4. POST `/echo` ด้วย `{"lot_id": "A1", "price": 85}` แล้วพิมพ์สิ่งที่ได้กลับมา
5. GET `/error` แล้วจับ error ด้วย try/except พร้อมพิมพ์ข้อความที่อ่านง่าย (ห้ามให้โปรแกรมหยุดกลางทาง)

ทุกคำขอต้องใส่ `timeout=10`
