# agent/ (agent ของทีม)

ที่นี่คือที่เก็บ agent ที่ทีมปรับปรุงจาก starter agent

- **ยังไม่มีกลยุทธ์** จะเริ่มเขียนหลังรู้กติกาและ API จริง (อบรมวันที่ 17–18 พ.ย.)
- โครงของ agent มี 3 ขั้น: ดู (เรียก API) → คิด (เลือกล็อต ผู้ซื้อ และราคา) → ทำ (ส่งข้อเสนอ) แล้ววนใหม่ [Track 3.pdf น.4]
- ช่วง 2 และ 3 agent ต้องส่งคำสั่งเอง ห้ามส่งด้วยมือ แต่แก้โค้ดระหว่างแข่งได้ [Track 3.pdf น.5]
- ให้ใช้ `../tools/log_template.py` บันทึกทุกคำขอ เพื่อไว้ตรวจย้อนหลังระหว่างแข่ง
- token และ URL ให้อ่านจาก `.env` เท่านั้น ห้ามเขียนลงในโค้ด
