# starter_agent/ (รอของจากผู้จัด)

ผู้จัดจะแจก starter agent ที่เล่นจนจบเกมได้ตั้งแต่แรก [Track 3.pdf น.4]

- ได้มาเมื่อไร: ให้วาง **ต้นฉบับ** ไว้ที่นี่ตามที่ได้รับ และอย่าแก้ไฟล์ในโฟลเดอร์นี้
- จะแก้หรือต่อยอด: ให้คัดลอกไปไว้ใน `../agent/` แล้วแก้ที่นั่นแทน
- แจกช่องทางไหน และต้องติดตั้งไลบรารีอะไรเพิ่ม: **ยังไม่ทราบ** (ดูคำถามข้อ 8 ใน `../docs/CHECKLIST.md`)
- ⚠️ ก่อน commit ให้ตรวจว่าไม่มี token หรือ URL ลับติดมาในโค้ด เพราะ repo นี้เป็น public
